Fine-Tuning Prep Notes

3 Recurring Issues

Inconsistent tone/format — Fine-tuning can help make answers more consistent and clear.

Mixed questions not fully answered — Fine-tuning can teach the model to answer every part of a question.

Missing policy information — This is a retrieval problem. Fine-tuning cannot fix it because the needed information was never retrieved.

Conclusion

Fine-tuning can improve how the model answers, but it cannot fix missing information from retrieval.
